## 解压运行

1. 完整解压到可写目录，例如桌面上的“数字逻辑演示”。不要在 ZIP 内运行。
2. 双击根目录 **一键启动.cmd**。包内运行时准备新库、迁移和完整模拟示例，启动 Web 与独立文件测评 worker。
3. 窗口显示本机网址、教师/学生/管理员账号和随机生成的演示口令。使用者的演示库、密钥与附件只保存在自己的 `.local-run/`。
4. 保留启动窗口，结束时双击 **停止运行.cmd**。再次启动保留历史。分享时发送原始 ZIP，不把使用后的目录重新打包。

默认仅监听 `127.0.0.1:5336`。端口冲突不会关闭其他程序，可在停止状态下修改 `.local-run/settings.json` 的 port。完整操作与故障定位见[一键运行说明](一键运行说明.md)和[用户手册](用户手册.md)。离线包会校验前端源码/构建产物和 Logisim JAR；源码修改后应重新构建发布包。

运行包只承诺本轮实测的 Windows64位本机演示；另一台电脑、实际局域网和正式课堂仍需现场确认。已有模拟示例不能作为真实课堂反馈或学习效果证据。第三方组件许可证随运行时保留，对应源代码入口见运行包 THIRD_PARTY.md。

## 重新生成运行包

在已安装锁定后端依赖的 Windows Python 环境中，先运行前端构建、提交源码，再执行：

```powershell
python scripts/build_release.py --out C:/delivery/v1.0.0 --python-runtime C:/portable-python --java-home C:/jdk21 --jar C:/tools/logisim-evolution-5.0.0-all.jar
```

Python目录需为可复制的64位 CPython运行时，版本与当前依赖环境相同；依赖从执行该脚本的 Python环境复制，许可证和 dist-info保留。输出目录必须在仓库外且 stage不存在。生成后须从 ZIP另行解压，使用包内工具执行启动、登录、真实文件判分、停止和数据保留检查后才发布。
