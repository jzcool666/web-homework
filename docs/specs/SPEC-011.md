# SPEC-011 约束智能组卷

版本：设计基线 1.0，2026-09-28。状态：待评审、未实现。模块对应：艾成斌。关联需求：FR-15。前置依赖：SPEC-009、SPEC-010。

## 1 范围

有限题库约束选题，参考历史作答提升针对性。非目标：生成新题、保证最优教学效果。

## 2 接口契约

E062 POST /paper-generations，count/difficulty_counts/knowledge_minimums/seed；成功生成Assessment草稿，422无解与503超时分开。

接口完整字段、角色缩写、状态码和公共错误定义见 [APIC](../../APIC.md)。所有写操作按公共规则校验会话、CSRF和对象权限；列表/导出同样不能越权。匿名401、角色拒绝403、跨班对象404、字段错误422、状态/版本冲突409；本模块特有错误以 APIC 为准。

## 3 数据结构

questions、question_knowledge、已公开的历史作答；结果和指纹存assessments.generation_json及items。

各字段类型、可空性、唯一键、外键、索引和删除策略见 [DBD](../../DBD.md)。涉及新表及索引时以迁移实现，不运行时自动建表覆盖已有数据。

## 4 业务规则

1. 候选为已发布可用题最多500；每题二元x_i。sum(x)=count；每难度选中数精确等于输入配额；每知识点覆盖数≥min_count；同题不可重复。
2. 难度配额和必须等于count。多标签题可同时覆盖多个知识点，因此不能仅因min_count之和>count就判无解。知识点最多18个。
3. Pandas统计目标班级已公开历史首答，p_i=(错误数+1)/(机会数+2)；NumPy构造目标优先级0.8*p_i+0.2*seed随机项，scipy.optimize.milp最小化其负值。
4. time_limit=2秒；最优或限时但有经整数/题量/难度/覆盖校验的可行解可返回，标solver_status=optimal/feasible；无可行解的超时503，不叫无解。证明无解返回422。
5. 记录候选题目版本指纹、种子、算法/求解器版本和所选题号。相同环境与输入可复现，不保证跨版本绝对相同。落库时版本变化409。
