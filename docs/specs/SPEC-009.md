# SPEC-009 题库练习与错题

版本：设计基线 1.0，2026-09-28。状态：待评审、未实现。模块对应：艾成斌。关联需求：FR-06。前置依赖：SPEC-001、SPEC-005。

## 1 范围

单选/多选/判断题、练习及作业考试共用测评模型、自动评分、错题视图。非目标：主观题自动评分和严格考试防作弊。

## 2 接口契约

E035—E047（课堂发布规则另见010）。QuestionWrite定义题型答案；保存答案{version,answers}；Result按feedback_available投影。

接口完整字段、角色缩写、状态码和公共错误定义见 [APIC](../../APIC.md)。所有写操作按公共规则校验会话、CSRF和对象权限；列表/导出同样不能越权。匿名401、角色拒绝403、跨班对象404、字段错误422、状态/版本冲突409；本模块特有错误以 APIC 为准。

## 3 数据结构

questions、question_knowledge、assessments、assessment_items、assessment_roster、submissions、submission_answers。

各字段类型、可空性、唯一键、外键、索引和删除策略见 [DBD](../../DBD.md)。涉及新表及索引时以迁移实现，不运行时自动建表覆盖已有数据。

## 4 业务规则

1. 选项key唯一；单选一个，多选至少两个正确项；selected集合完全相同才得该题全部分，空答案0分。
2. 教师发布时冻结题目版本、答案、解析、标签及分值；后来改题不回写历史。
3. 学生自练从已发布题库创建，本人单人名单、24小时期限、提交后立即反馈；每次重练生成新测评。本人所在班级中已发布但尚未公开反馈的班级测评所用题，对其学生的自练/推荐排除；结束不等于公开，已结束但未公开反馈的测评题同样排除，直到 feedback_released=true，避免旁路泄露。
4. 草稿先保存，再最终化；答案字段来自服务器题目快照，拒绝客户端score/correct。已提交不能再改。
5. 首答按学生+题目最早已提交的机会，漏答也计错误；重练单独展示。错题resolved只看最近已公开的已提交答案正确性，历史错题仍可查。
