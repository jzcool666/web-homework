# SPEC-000 公共工程与运行约定

版本：设计基线 1.0，2026-09-28。状态：工程骨架已实现，执行结果见[报告](../testing/SPEC-000-执行报告.md)。模块对应：吴亚峰。关联需求：FR-01、NFR-02/03/06/07。前置依赖：无。

## 1 范围

建立前后端工程、配置、迁移、测试基础和生产启动契约。非目标：不在设计阶段创建应用或安装依赖；不定义账号业务，管理员初始化归 SPEC-001，完整业务种子随各业务模块交付。

## 2 接口契约

E000 GET /api/v1/health（前缀见 APIC 第1节）→ 公共封装 `{data,meta}`，data 为 `{status,version}`；数据库不可用返回 503 错误封装及可读原因。

接口完整字段、角色缩写、状态码和公共错误定义见 [APIC](../../APIC.md)。所有写操作按公共规则校验会话、CSRF和对象权限；列表/导出同样不能越权。匿名401、角色拒绝403、跨班对象404、字段错误422、状态/版本冲突409；本模块特有错误以 APIC 为准。

## 3 数据结构

所有表的公共字段与 Alembic 版本；本模块先建立迁移和测试配置，业务表由各模块迁移追加。

各字段类型、可空性、唯一键、外键、索引和删除策略见 [DBD](../../DBD.md)。涉及新表及索引时以迁移实现，不运行时自动建表覆盖已有数据。

## 4 业务规则

1. Flask create_app 支持 testing 配置，测试数据库为临时路径；启动不得自动清空数据库。
2. Vite 开发代理 /api；部署同源。健康接口不输出环境变量、路径或凭据。
3. 依赖锁定后记录 Python/Node/操作系统版本；初始化类命令相互分离且幂等，且不得重置正式数据。本 Spec 只提供迁移与测试所需的基础数据，管理员初始化归 SPEC-001，完整业务种子随各业务模块交付。
4. 生产 WSGI 启动与前端构建在新目录实测；SQLite foreign_keys 与 busy_timeout 每连接执行。
