# SPEC-002 考勤与请假

版本：设计基线 1.0，2026-09-28。状态：已实现，执行结果见[报告](../testing/SPEC-002-执行报告.md)。模块对应：吴亚峰。关联需求：FR-09。前置依赖：SPEC-001。

## 1 范围

数字签到码、出勤状态、请假审批和缺勤结算。非目标：定位、二维码、防代签保证。

## 2 接口契约

E028—E034。创建 class_id/title/opens_at/late_at/closes_at；签到 code；审批 version/status/review_note；返回 AttendanceTask/AttendanceRecord/Leave。

接口完整字段、角色缩写、状态码和公共错误定义见 [APIC](../../APIC.md)。所有写操作按公共规则校验会话、CSRF和对象权限；列表/导出同样不能越权。匿名401、角色拒绝403、跨班对象404、字段错误422、状态/版本冲突409；本模块特有错误以 APIC 为准。

## 3 数据结构

attendance_tasks、attendance_records、leave_requests；每任务每学生唯一。

各字段类型、可空性、唯一键、外键、索引和删除策略见 [DBD](../../DBD.md)。涉及新表及索引时以迁移实现，不运行时自动建表覆盖已有数据。

## 4 业务规则

1. 发布时复制有效班级名单为pending；六位码只向教师创建/重置响应显示，保存散列。
2. 签到窗口[opens_at,closes_at)，小于late_at为present，否则late；重复有效签到返回原记录。
3. 截至结束仍pending才转absent；无访问时未结算不显示为已缺勤。统计读取可触发结束任务结算。
4. 请假结束前申请，审批可在结束后完成；批准将pending/absent改leave。present/late不能改leave，已批准者不能签到。
5. 重置签到码使旧码立即失效；一分钟5次错误后429。
6. 停用班级不得新建签到任务、签到、请假或重置签到码；学生离开班级后，不能仅凭发布时的名单快照继续提交新签到或请假，历史记录仍可查询。
