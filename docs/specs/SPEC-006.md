# SPEC-006 学习进度与资源统计

版本：设计基线 1.0，2026-09-28。状态：待评审、未实现。模块对应：尹仕铭。关联需求：FR-11。前置依赖：SPEC-005。

## 1 范围

章节进度、学生完成率、资源访问分布和导出。非目标：把点击次数估算成学习时长或掌握度。

## 2 接口契约

E056 GET /analytics/learning {class_id,from?,to?,chapter_id?,format?} → LearningStats，公开progress_basis。

接口完整字段、角色缩写、状态码和公共错误定义见 [APIC](../../APIC.md)。所有写操作按公共规则校验会话、CSRF和对象权限；列表/导出同样不能越权。匿名401、角色拒绝403、跨班对象404、字段错误422、状态/版本冲突409；本模块特有错误以 APIC 为准。

## 3 数据结构

learning_progress、knowledge_points、resource_events、resource_versions、enrollments。

各字段类型、可空性、唯一键、外键、索引和删除策略见 [DBD](../../DBD.md)。涉及新表及索引时以迁移实现，不运行时自动建表覆盖已有数据。

## 4 业务规则

1. 完成率=当前已完成且completed_at<to的已发布知识点数/当前已发布知识点数；分母为0则null。属于当前快照近似，不重建历史撤销记录。
2. from只过滤资源事件，页面必须分别标注进度快照与访问时间窗；当前已退班学生不计当前进度名单，历史活动统计仍保留。
3. 资源统计按事件UTC日窗口聚合并显示去重人数和去重事件数，同人多个版本访问可计多个事件，但人数只计一次。
4. Pandas完成groupby/去重；CSV与同筛选JSON一致。
5. 资源事件按UTC日去重，筛选使用UTC整日边界；非整日from/to返回422。默认最近30个UTC自然日，到当前UTC日下一日00:00截止，避免把按日记录误当精确访问时刻。页面标注统计时区。
