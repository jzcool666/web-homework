# SPEC-012 课堂演示与时序仿真

2026-10-03范围说明：本Spec继续保留四个预置简化模型；原厂芯片引脚与低有效异步控制、自由接线过程另由[SPEC-018](SPEC-018.md)实现，不替换本Spec的同步高有效reset。

版本：设计基线 1.0，2026-09-28。状态：已实现，执行结果见[报告](../testing/SPEC-012-执行报告.md)。模块对应：孙之宁。关联需求：FR-04/05、NFR-04/05。前置依赖：SPEC-001、SPEC-005。

## 1 范围

预置D、JK、4位计数器、4位移位寄存器；单步、复位、预测、投屏、学生同步。非目标：任意连线、模拟延迟、亚稳态。

## 2 接口契约

E048/E049实验定义；E052—E054共享演示，POST action expected_version/event → Demo；规则见第4节。

接口完整字段、角色缩写、状态码和公共错误定义见 [APIC](../../APIC.md)。所有写操作按公共规则校验会话、CSRF和对象权限；列表/导出同样不能越权。匿名401、角色拒绝403、跨班对象404、字段错误422、状态/版本冲突409；本模块特有错误以 APIC 为准。

## 4 业务规则

1. 初始clock=0，Q由config指定；set仅改输入，toggle_clock翻转时钟。仅0→1计算新Q，1→0和单独改输入不改变Q。
2. reset为同步高有效：在上升沿优先Q=0；否则D为Q'=D，JK:00保持/01置0/10置1/11翻转。
3. counter: enable=0保持；否则Q'=(Q+1) mod M，M为2—16；无效Q≥M在下个有效沿回0。shift右移：Q'=(serial_in<<3)|(Q>>1)，enable=0保持，显示Q3Q2Q1Q0。
4. 默认enable=1，其余输入0。reset_view恢复初始Q、clock和输入并清空历史，区别于同步reset引脚；最多128事件，超出提示重置。
5. 每事件记录时钟、输入、旧Q、新Q和是否有效沿；屏幕只在有效沿高亮变化。预测模式隐藏尚未执行的Q'；已执行历史可见。
6. 教师action由服务器从旧状态重算并递增version；学生每3秒获取只读状态。断线显示最后版本，恢复重新获取完整状态；不自动重放过期控制请求。
7. Demo.next_q表示按当前输入计算的下一个有效上升沿状态；reveal_next=false时返回null。state.step_no为已执行有效上升沿数量，history每个事件均记录，下降沿不增加step_no。reset_view将step_no归零。
8. 同一版本的并行动作只允许一条原子写入，其余返回409；切换实验模型时现有配置与输入序列必须按新模型重新校验。停用班级不再开启或继续控制演示，但允许结束已有演示和读取历史。
