# SPEC-004 学习预警与分组

版本：设计基线 1.0，2026-09-28。状态：待评审、未实现。模块对应：吴亚峰。关联需求：FR-16。前置依赖：SPEC-003、SPEC-006、SPEC-010。

## 1 范围

可解释统计预警和数据充足时的班级聚类。非目标：预测挂科概率、自动处罚或医疗/心理判断。

## 2 接口契约

E063 POST /warnings/generations {class_id,from?,to?}；E064 GET /warnings；返回Warning含证据、样本量、score和cluster_label。

接口完整字段、角色缩写、状态码和公共错误定义见 [APIC](../../APIC.md)。所有写操作按公共规则校验会话、CSRF和对象权限；列表/导出同样不能越权。匿名401、角色拒绝403、跨班对象404、字段错误422、状态/版本冲突409；本模块特有错误以 APIC 为准。

## 3 数据结构

warning_snapshots及统计源表；快照带algorithm_version和窗口，教师显式生成。

各字段类型、可空性、唯一键、外键、索引和删除策略见 [DBD](../../DBD.md)。涉及新表及索引时以迁移实现，不运行时自动建表覆盖已有数据。

## 4 业务规则

1. 风险因素a=1-出勤率，p=1-完成率，e=1-知识点首答正确率。权重分别0.3/0.2/0.5，可用项归一化，score=100×加权和。
2. 出勤至少1个已结算有效分母；进度至少1条明确完成/未完成记录且知识点分母>0；答题至少3次首答。至少2项可用才评分，否则insufficient。
3. score<30为low，30≤score<60为medium，≥60为high。这是项目规则，不是经训练校准的学业风险概率。
4. 使用Pandas/NumPy真实聚合和运算。有完整三因素的学生n≥10且不同向量≥3时，KMeans(k=3,random_state=42,n_init=10)分组；按中心平均风险排序编号0/1/2，不覆盖规则等级。否则cluster_label=null。
5. 保存生成时间和证据；只读取最近同窗口完整批次。后续数据变化需再次生成，不称旧快照为实时数据。
