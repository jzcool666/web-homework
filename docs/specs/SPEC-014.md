# SPEC-014 实验学习统计

版本：设计基线 1.0，2026-09-28。状态：待评审、未实现。模块对应：孙之宁。关联需求：FR-13。前置依赖：SPEC-013。

## 1 范围

实验参与人数、通过人数、尝试量和导出。非目标：未经采集的学习时长。

## 2 接口契约

E058 GET analytics/experiment {class_id,from?,to?,experiment_id?,format?} → ExperimentStats。

接口完整字段、角色缩写、状态码和公共错误定义见 [APIC](../../APIC.md)。所有写操作按公共规则校验会话、CSRF和对象权限；列表/导出同样不能越权。匿名401、角色拒绝403、跨班对象404、字段错误422、状态/版本冲突409；本模块特有错误以 APIC 为准。

## 3 数据结构

experiment_attempts、experiments、enrollments。

各字段类型、可空性、唯一键、外键、索引和删除策略见 [DBD](../../DBD.md)。涉及新表及索引时以迁移实现，不运行时自动建表覆盖已有数据。

## 4 业务规则

1. 使用Pandas按实验和学生聚合窗口内尝试；参与人数为至少提交一次完整预测的学生数。
2. 同实验同学生多次尝试只计一个参与者，任一次通过计一个通过者；尝试数不去重（幂等重试除外）。
3. 单实验通过率=通过学生/参与学生，无参与返回null；总通过人数指至少通过一个实验，页面用明确标签。
4. 当前有效班级名单限制实验统计，退班历史仍保留在个人记录；若未来要求历史班级归属分析，另立变更，不从当前名单倒推。
