# SPEC-001 账号角色与班级权限

版本：设计基线 1.0，2026-09-28。状态：待评审、未实现。模块对应：吴亚峰。关联需求：FR-01、NFR-01。前置依赖：SPEC-000。

## 1 范围

三角色账号、个人资料、管理员班级分配和服务端对象权限。非目标：短信、第三方登录、自助教师注册。

## 2 接口契约

E001—E010。注册字段 login_name/student_no/display_name/password；登录返回 User 与 csrf_token；班级写入 name/teacher_id，入班写入 student_id/active。模型见 APIC 第2、3节。

接口完整字段、角色缩写、状态码和公共错误定义见 [APIC](../../APIC.md)。所有写操作按公共规则校验会话、CSRF和对象权限；列表/导出同样不能越权。匿名401、角色拒绝403、跨班对象404、字段错误422、状态/版本冲突409；本模块特有错误以 APIC 为准。

## 3 数据结构

users、sessions、classes、enrollments；学生学号唯一、最多一个 active 班级。

各字段类型、可空性、唯一键、外键、索引和删除策略见 [DBD](../../DBD.md)。涉及新表及索引时以迁移实现，不运行时自动建表覆盖已有数据。

## 4 业务规则

1. 匿名 CSRF 会话30分钟，登录会话绝对8小时；登录轮换 token，退出删除，改密码撤销全部登录。
2. 注册强制student，禁止写role/active；未入班学生仅可访问个人页。
3. 每请求验证用户active和班级关系；教师只读写自己班级的课堂记录，管理员不隐式获得教师答案接口。
4. 管理员不可禁用或降级最后一个有效管理员；班级换教师后即时调整历史教学数据权限。
