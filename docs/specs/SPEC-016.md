# SPEC-016 时序逻辑知识图谱与可视化

版本：设计基线 1.0，2026-09-28。状态：待评审、未实现。模块对应：尹仕铭。关联需求：FR-18。前置依赖：SPEC-005。

## 1 范围

读取 SPEC-005 课程种子中的先修关系（knowledge_edges），提供时序逻辑知识点的邻接、先修路径、拓扑序和子图查询，供前端图形化展示。非目标：关系网页编辑、通用知识本体、图数据库、从文本自动抽取关系、任意学科图谱。

## 2 接口契约

E066 GET /knowledge-graph（chapter_id?/root_id?/depth? → nodes/edges）；E067 GET /knowledge-graph/path（from/to → 最短先修链）；E068 GET /knowledge-graph/topological（chapter_id? → order/has_cycle）。三者均为只读投影，边界规则见第4节。

接口完整字段、角色缩写、状态码和公共错误定义见 [APIC](../../APIC.md)。所有写操作按公共规则校验会话、CSRF和对象权限；列表/导出同样不能越权。匿名401、角色拒绝403、跨班对象404、字段错误422、状态/版本冲突409；本模块特有错误以 APIC 为准。

## 3 数据结构

knowledge_edges（先修关系，字段与约束见 SPEC-005）；图查询结果按请求实时计算，不另建缓存表。

各字段类型、可空性、唯一键、外键、索引和删除策略见 [DBD](../../DBD.md)。涉及新表及索引时以迁移实现，不运行时自动建表覆盖已有数据。

## 4 业务规则

1. 边方向为 prerequisite_id→target_id，即先修指向后继；图由 knowledge_points 与 knowledge_edges 构建。
2. 只包含已发布知识点；涉及草稿节点的边不进入任何响应。
3. 服务层检测环，最多 1000 条边。存在环时 has_cycle=true 并返回环上各边，不输出拓扑序；无环时拓扑序唯一确定，同层按 sort_order、id 排序。
4. depth 取 1—3，默认 1；以 root 为中心沿先修边的两个方向查找相邻知识点，depth 为忽略方向后的最短边数，但响应中的边仍保持先修→后继方向。子图节点上限 200，超出按到 root 的距离裁剪并置 truncated=true，不静默丢弃。
5. 先修路径用 BFS 求最短路；两端无路径时 matched=false 且节点为空，不编造中间节点。
6. 本模块不提供写接口；本期先修关系由 SPEC-005 的课程种子写入并经无环校验，不提供网页编辑或公开的关系写接口。后续如需编辑，先扩展 SPEC-005 与 APIC。
7. 前端用 ECharts 关系图渲染，节点按章节或深度区分，并以文字、编号同时标注，颜色不作唯一编码。
