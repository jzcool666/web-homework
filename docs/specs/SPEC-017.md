# SPEC-017 时序逻辑识别辅助

版本：设计基线 1.0，2026-09-28。状态：待评审、未实现。模块对应：孙之宁。关联需求：FR-19。前置依赖：SPEC-012。

## 1 范围

对规定格式的时序逻辑状态表图片做识别：分割表格、判定单元格 0/1、组装现态序列并推导相邻拍的次态转换，输出供学生核对。非目标：任意手绘电路图、卡诺图化简、元件符号与连线识别、照片透视恢复；不声称通用图像识别，也不以识别结果替代实验判分。

## 2 接口契约

E069 POST /recognition-tasks（multipart 图片 + kind:state_table → 任务）；E070 GET /recognition-tasks/{id}（任务结果）。处理同步完成并限时，规则见第4节。

接口完整字段、角色缩写、状态码和公共错误定义见 [APIC](../../APIC.md)。所有写操作按公共规则校验会话、CSRF和对象权限；列表/导出同样不能越权。匿名401、角色拒绝403、跨班对象404、字段错误422、状态/版本冲突409；本模块特有错误以 APIC 为准。

## 3 数据结构

新增 recognition_tasks（owner_id、kind、storage_key、mime、size_bytes、status、result_json、error_json）；图片按 ADR-008 规则落盘。

各字段类型、可空性、唯一键、外键、索引和删除策略见 [DBD](../../DBD.md)。涉及新表及索引时以迁移实现，不运行时自动建表覆盖已有数据。

## 4 业务规则

1. 仅接受 PNG/JPEG，单文件不超过 20MiB；以随机 storage_key 保存，原始文件名只显示不拼接磁盘路径；不抓取外部 URL。
2. 识别流程：灰度化→二值化→检测规则网格线→切分单元格→按占空比与像素阈值判定每格 0/1→按行列组装状态序列→由相邻行推导次态转换对。
3. 输入必须是规定格式：规则网格、每格单个 0/1、按拍序排列。不满足时 status=failed 并给出具体原因（未检测到网格／格内非0/1／行列数不符），不返回猜测结果。
4. 使用 OpenCV/Pillow，不使用深度学习模型；同一图片与同一阈值参数可复现，不保证跨分辨率绝对一致。
5. 识别结果为辅助信息，附置信度与“需人工核对”标注；实验判分仍由 SPEC-013 后端从配置与输入序列重算，不采信识别结论或客户端字段。
6. 任务仅创建者及其任教该班的教师可读，跨班返回404；图片不外发第三方。
7. 处理同步完成并限时，超时返回503可重试，不引入后台队列；失败任务不保留有效结果记录。
