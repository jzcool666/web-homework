# SPEC-010 随堂测与测评统计

版本：设计基线 1.0，2026-09-28。状态：待评审、未实现。模块对应：艾成斌。关联需求：FR-07/12、NFR-05。前置依赖：SPEC-009。

## 1 范围

短测、截止和草稿恢复、教师讲评、成绩和选项统计。非目标：WebSocket秒级竞赛、监考。

## 2 接口契约

E037—E046课堂状态；E057 analytics/assessment；发布starts_at/ends_at，结束/公开反馈需version。

接口完整字段、角色缩写、状态码和公共错误定义见 [APIC](../../APIC.md)。所有写操作按公共规则校验会话、CSRF和对象权限；列表/导出同样不能越权。匿名401、角色拒绝403、跨班对象404、字段错误422、状态/版本冲突409；本模块特有错误以 APIC 为准。

## 3 数据结构

测评全表及发布名单；Pandas统计，无独立分数缓存。

各字段类型、可空性、唯一键、外键、索引和删除策略见 [DBD](../../DBD.md)。涉及新表及索引时以迁移实现，不运行时自动建表覆盖已有数据。

## 4 业务规则

1. 状态draft→published→closed；effective_state依据服务器时间。学生只在[starts_at,ends_at)开始、保存或提交。
2. 截止读取/统计/提交入口先幂等最终化已开始草稿；没开始的仍未提交。教师可提前关闭；公开答案只能有效结束后。
3. 默认讲评前学生只能确认已提交，score与correct均不可见；投屏统计匿名。教师可提前查看统计，投屏公开由教师控制。结束不等于公开：反馈公开前，该测评题目不进入自练与推荐候选。
4. 草稿变化后短延迟保存（建议1秒），最终提交必须等待保存确认；断线显示最后保存时间，不伪报成功。
5. 班级成绩mean_percent仅包含已提交测评；提交率分母为快照名单；各题正确率分母为已提交人数（包括漏答），选项各计一次，漏答单列。
6. 知识点首答机会基于全历史最早答案，再按其submitted_at窗口筛选；不是窗口内第一次。分数段0—<60、60—<70、70—<80、80—<90、90—100。
7. 学生刷新或登录恢复后，通过Assessment.my_submission_id定位本人记录，再通过开始作答接口取得已有草稿或通过result取得最终结果。截止最终化保存submitted_at=ends_at，手动提前关闭使用实际关闭时间；统计窗口不取后台延迟处理时间。
