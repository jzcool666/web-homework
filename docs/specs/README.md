## 实施依赖顺序

先完成000、001。随后002与005互不依赖；005完成后，006、007、009、012可以分别推进。010依赖009，013依赖012，008依赖005/009/012，014依赖013。003依赖002/006/010，004依赖003/006/010，011依赖009/010，015依赖006/009/014。016依赖005，017依赖012，二者属智能功能阶段，可与011/015并行。全部模块验收后进入系统集成。

20份规格各四组验收，共80组，详见[测试计划](../testing/需求追溯与测试计划.md)，新增8组已通过本机验收，见[实验扩展验收报告](../testing/实验扩展验收报告.md)，已通过独立评审并合入。归属见[覆盖矩阵](../testing/任务书功能覆盖矩阵.md)。实验扩展先LAB-0共享基础，再并行LAB-1接线界面与LAB-2文件测评，最后LAB-3集成；公共入口与契约串行处理，详见[方案](../design/实验箱接线与电路测评方案.md)。
