## 实施依赖顺序

先完成000、001。随后002与005互不依赖；005完成后，006、007、009、012可以分别推进。010依赖009，013依赖012，008依赖005/009/012，014依赖013。003依赖002/006/010，004依赖003/006/010，011依赖009/010，015依赖006/009/014。全部模块验收后进入系统集成。

这些是最早可开始的条件，互不依赖的模块可以并行。各模块四条验收用例共64条，详见[测试计划](../testing/需求追溯与测试计划.md)。未实现模块不得提前记为通过。
