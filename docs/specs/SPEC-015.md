# SPEC-015 个性化复习推荐

版本：设计基线 1.0，2026-09-28。状态：待评审、未实现。模块对应：孙之宁。关联需求：FR-17。前置依赖：SPEC-006、SPEC-009、SPEC-014。

## 1 范围

为学生排序知识点与练习入口，解释原因。非目标：给教师推送个人画像或声称推荐能提高成绩。

## 2 接口契约

E065 GET /me/recommendations {limit?} → items含kind/resource_id/knowledge_id/title/score/reasons。

接口完整字段、角色缩写、状态码和公共错误定义见 [APIC](../../APIC.md)。所有写操作按公共规则校验会话、CSRF和对象权限；列表/导出同样不能越权。匿名401、角色拒绝403、跨班对象404、字段错误422、状态/版本冲突409；本模块特有错误以 APIC 为准。

## 3 数据结构

learning_progress、已公开submission_answers、experiment_attempts、knowledge_edges、questions；首版不新建推荐缓存表。

各字段类型、可空性、唯一键、外键、索引和删除策略见 [DBD](../../DBD.md)。涉及新表及索引时以迁移实现，不运行时自动建表覆盖已有数据。

## 4 业务规则

1. 按知识点聚合已公开首答错误率e、明确未完成记录p（未完成1/完成0）、实验失败比例x。NumPy按0.5/0.3/0.2对可用项归一化，缺失项不当失败。
2. 只使用本人记录；无任何信号时按章节顺序推荐基础知识点，理由为入门路径，不显示虚构个性化得分。
3. 有薄弱知识点时优先返回其未完成先修知识点，再返回该知识点与未做练习；已完成且首答正确率≥.8且实验通过的内容降序或排除。
4. 推荐不返回题目答案；本人所在班级中已发布但尚未公开反馈的班级测评所用题排除，结束不等于公开，已结束但未公开反馈的同样排除，直到反馈公开，避免旁路泄题。最多返回limit条，不足时不重复凑数。
5. 同分按章节顺序和ID排序。每条理由来自实际可用因素，不写不存在的错误次数。
