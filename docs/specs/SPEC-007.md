# SPEC-007 课程检索问答

版本：设计基线 1.0，2026-09-28。状态：待评审、未实现。模块对应：尹仕铭。关联需求：FR-14。前置依赖：SPEC-005。

## 1 范围

检索已发布课程知识与问答，展示来源摘要。非目标：自由生成未核实答案、联网搜题或保证所有问题可答。

## 2 接口契约

E059/E060管理QAEntry；E061 POST /qa/queries {query} → matched/corpus_version/matches，每条含source_url和similarity。

接口完整字段、角色缩写、状态码和公共错误定义见 [APIC](../../APIC.md)。所有写操作按公共规则校验会话、CSRF和对象权限；列表/导出同样不能越权。匿名401、角色拒绝403、跨班对象404、字段错误422、状态/版本冲突409；本模块特有错误以 APIC 为准。

## 3 数据结构

qa_entries、knowledge_points；向量索引为可重建内存数据，语料指纹由ID/版本构成。

各字段类型、可空性、唯一键、外键、索引和删除策略见 [DBD](../../DBD.md)。涉及新表及索引时以迁移实现，不运行时自动建表覆盖已有数据。

## 4 业务规则

1. 文本去空白归一化，TfidfVectorizer(analyzer='char',ngram_range=(2,4))，cosine_similarity；索引只读已发布文本，不含测评答案。
2. 默认相似度阈值0.2，取最多3条；所有结果低于阈值或语料为空则matched=false。阈值作为待校准参数，不把相似度解释为正确概率。
3. 语料修改后下一次查询重建指纹不同的索引；并发请求只让一个线程构建，失败保留旧索引并显式报错，不返回混合版本。
4. 查询2—200字符，单用户每分钟20次，超过429；摘要最多300字，展示知识点和来源。
5. 实现阶段准备20条人工标注查询，其中5条域外；至少12/15域内问题Top3包含相关知识点，5条域外全部拒答为目标，未实测前不声称达到。
