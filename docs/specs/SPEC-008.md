# SPEC-008 备课与预习发布

版本：设计基线 1.0，2026-09-28。状态：待评审、未实现。模块对应：尹仕铭。关联需求：FR-03。前置依赖：SPEC-005、SPEC-009、SPEC-012。

## 1 范围

备课清单、模板复制、授课计划和班级预习。非目标：学校课表排课与消息推送平台。

## 2 接口契约

E023—E027；PlanItem为target_type/target_id/sort_order；发布{class_id,plan_id,due_at?} → Preview。

接口完整字段、角色缩写、状态码和公共错误定义见 [APIC](../../APIC.md)。所有写操作按公共规则校验会话、CSRF和对象权限；列表/导出同样不能越权。匿名401、角色拒绝403、跨班对象404、字段错误422、状态/版本冲突409；本模块特有错误以 APIC 为准。

## 3 数据结构

lesson_plans、lesson_plan_items、preview_assignments及被引用的知识点/资源版本/题目/实验。

各字段类型、可空性、唯一键、外键、索引和删除策略见 [DBD](../../DBD.md)。涉及新表及索引时以迁移实现，不运行时自动建表覆盖已有数据。

## 4 业务规则

1. 一份备课单可引用多个知识点、资源版本、题目、实验；条目顺序唯一，每条恰好一个目标。
2. 只引用可见内容，未发布他人草稿不可引用；题目发布给学生时剔除答案和解析。
3. 复制只生成新计划与条目，文件和题库不复制；发布保存不可变预习快照。
4. 预习推送首版为学生首页待办列表，不发短信、邮件或外部通知。
