# SPEC-013 实验辅助与结果验证

2026-10-03范围说明：本Spec为预测序列判分；虚拟连线和circ真实引擎判分另由[SPEC-018](SPEC-018.md)/[SPEC-019](SPEC-019.md)实现，不能将本Spec已通过当作新增要求已完成。

版本：设计基线 1.0，2026-09-28。状态：已实现（学生端），执行结果见[报告](../testing/SPEC-013-执行报告.md)。模块对应：孙之宁。关联需求：FR-08。前置依赖：SPEC-012。

## 1 范围

固定实验输入下预测每个有效上升沿后的状态，后端验证并返回差异。非目标：仅点击运行就认定学会。

## 2 接口契约

E050提交 experiment_version/predictions/request_key；E051本人历史列表与单条查询（他人记录404）；AttemptResult含expected和first_error_index。

接口完整字段、角色缩写、状态码和公共错误定义见 [APIC](../../APIC.md)。所有写操作按公共规则校验会话、CSRF和对象权限；列表/导出同样不能越权。匿名401、角色拒绝403、跨班对象404、字段错误422、状态/版本冲突409；本模块特有错误以 APIC 为准。

## 3 数据结构

experiments、experiment_attempts，快照包括模型配置和输入序列。

各字段类型、可空性、唯一键、外键、索引和删除策略见 [DBD](../../DBD.md)。涉及新表及索引时以迁移实现，不运行时自动建表覆盖已有数据。

## 4 业务规则

1. 四个实验覆盖D、JK、模6计数器、4位移位寄存器；每个有不少于4个有效沿检查点。
2. 学生只能提交预测序列和版本，输入序列由服务器实验快照固定；服务端重算，prediction长度必须等于检查点数。
3. first_error_index从0开始，界面显示第index+1拍。全部相等passed=true；只有完全提交并比较的记录计完成。
4. request_key按学生唯一，同key同payload返回原结果，不同payload409；旧experiment_version请求409要求刷新。
