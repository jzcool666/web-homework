# 课堂演示与验收示例

本说明配合[用户手册](用户手册.md)使用。示例全部为模拟数据；成绩、出勤和分组不能作为真实教学效果或成员开发贡献的证明。

## 1 建立演示库

先安装依赖、构建前端，并把 DATABASE_URL/UPLOAD_DIR 指向仓库外的新演示目录。工作目录为 backend，先迁移，再初始化；这套完整示例不需要先执行 init-admin 或单个 seed 命令。

```powershell
# 已设置演示库的 DATABASE_URL、UPLOAD_DIR 和运行环境
python -m flask --app app:create_app db upgrade
# DEMO_PASSWORD自行提供10—128字符临时演示口令，不使用真实个人口令
python -m flask --app app:create_app seed-demo --confirm-demo-database
```

命令从 `DEMO_PASSWORD` 环境变量读取口令，不回显。首次创建18账号和两班；重复运行不重置口令、不续期、不覆盖课堂或学习记录。发现非演示账号或不完整保留账号集合会拒绝；这种情况下另建演示库，不要清理原库。正式账号库按用户手册的管理员初始化流程操作。

| 账号 | 角色/班级 | 适合演示 |
| --- | --- | --- |
| demo_admin | 演示管理员 | 账号、班级和入班 |
| demo_teacher_a | 演示教师A / A班12人 | 主课堂、题库、备课、讲评、数据分析和智能工具 |
| demo_teacher_b | 演示教师B / B班3人 | 独立空课堂、跨班隔离 |
| demo_student_01 | A班 | 错题先错后对、实验先错后对、复习建议 |
| demo_student_02—11 | A班 | 不同模拟成绩、进度、出勤和实验情况 |
| demo_student_12 | A班 | 未开始课堂测评、样本不足；自练不会混入教师班级测评首答 |
| demo_student_13—15 | B班 | 课程冷启动和跨班隔离 |

所有初始口令取自首次初始化时的 DEMO_PASSWORD。进行中随堂测只在初次初始化后一天内开放，预习截止为七天后；过期后由教师正常创建新任务。所有模拟历史相对首次导入时间生成。

## 2 建议演示顺序

1. 教师A登录首页，选择“演示班A（模拟数据）”，确认真实读取的课堂、随堂测和统计，不使用手填的首页数字。
2. 进入课堂，继续初始计数器演示；逐拍观察0—5回卷，先让学生预测，再揭示下一状态。可结束当前演示后选择D、JK或寄存器，展示输入开关、输出灯和寄存器移位。打开独立投屏并全屏。
3. 学生01在另一浏览器登录“我的课堂”，同步观看；教师保持预测隐藏时学生不能看到下一状态。学生不能使用教师控制按钮。
4. 教师进入“测评与讲评”，选择“演示随堂测 · 现在作答”。学生保存并提交，教师结束后公开反馈再讲评。另有“已讲评（模拟历史）”可直接展示白卷、漏答与未提交的统计区别。
5. 学生01看错题本：既有“已纠正”也有“未纠正”。勾选未纠正题重练，成绩由正式判分服务计算，答对也不会擦掉首次错误。
6. 进入实验，先预测计数器或寄存器，故意错一拍观察首错说明，再正确提交；历史页保留两次尝试。教师实验管理可以编辑输入事件和发布草稿，旧版本冲突有明确提示。
7. 看课程知识和图谱，选择先修路径；智能问答分别输入课程问题与域外问题，观察命中与“不匹配”分支；学生复习推荐显示相关记录理由。
8. 教师学习预警点击“生成快照”。初始化没有预填假算法结果；生成后应有三种KMeans分组及样本不足学生。等级是项目规则分数档，不是挂科概率。
9. 教师智能组卷选择合理的知识点、题数和难度，预览再采用草稿；再设置不可能条件，确认返回可读的不足原因，而不是硬凑一套题。
10. 教师A新发起考勤，记录一次性签到码；学生签到、请假，教师审批和结算。初始三次模拟考勤用于展示统计，不包含可复用明文签到码。

## 3 实验箱、文件测评和识别

实验箱与课堂同步模型有所区别：真实芯片会涉及低有效异步控制等引脚行为，按任务提示接线。进入四个任务，选择器件、连接引脚、上电检查，再使用输入开关与时钟，观察输出灯、过程和服务器判分。错误接线应给出具体提示。接线过程仍使用正式接口，不在初始库中伪造一条满分接线记录。

文件测评必须另启 `lab-worker`，设置同一 DATABASE_URL/UPLOAD_DIR 和有效的 LAB_JAVA/LAB_JAR。使用仓库[examples](../examples/README.md)中的 `correct.circ` 与 `wrong.circ` 分别上传。正确文件通过、合法错误文件不通过，并查看首错；教师只读本班记录。没有worker时应显示服务不可用，不能宣称完成了文件判分。

识别辅助使用 examples/recognition 的状态表和空白反例；正确表为0→1→2→3→4→5→0，应得到6个次态对。空白图片应提示没有网格。识别结果只供人工核对，不自动作为成绩。

## 4 验收边界

同一套演示数据适合界面走查、录制演示和技术验收。真实课堂使用、60名真实学生参与、Gitea迁移及课程组号需另按实际情况补充，不把模拟数据改写成已发生的课堂活动。性能、备份恢复、权限矩阵和完整回归必须有独立实测记录，不能仅凭页面有数字就判断通过。
