# 教师实验管理检查记录

日期：2026-10-03。基线：develop a3f17dd，分支 feature/teacher-experiments，实现提交98f17c1，关联 Issue #52。使用本分支构建产物、Waitress 同源服务与项目外的独立 SQLite 库验证；账号、班级及实验为验收样本，未改正式数据库。

## 实现范围

- 教师导航“实验”接通 `/teacher/experiments`，提供可见实验列表、标题搜索、本人筛选、新建与编辑。
- 支持 D、JK、4位计数器与4位移位寄存器；填写关联知识点、初态、计数模数和说明。已有序列时禁止直接换模型，先移除原序列再更换，避免混入另一模型的输入。
- 输入序列使用操作列表编辑：设置输入、添加半周期或一拍、恢复初态、上移下移与移除。显示 CLK 和有效沿检查点数量，最多128事件；标准输出和判分仍由原后端负责。
- 创建走 E048，编辑走 E049 并携带当前 version；保存采用服务器回执。支持草稿、发布及撤回。他人公开实验只读，不提供写入按钮。
- 409时保留输入并停止提交，明确重新载入后才替换内容；422展示字段原因。会话校验失败时保留内容并清除本页旧令牌缓存，提示再次保存，不自动重试或推进版本号。
- 无后端、接口契约、Spec、数据库迁移或依赖变更；未实现实验删除。

## 真实浏览器流程

Playwright操作真实登录表单、下拉框与按钮，未用DOM事件替代鼠标点击。最终记录20项检查；其中提交历史、演示快照与绕过界面的权限验证为同源接口检查，其余为页面交互与尺寸检查。

| 场景 | 实际结果 |
| --- | --- |
| 建模6实验 | 初态4、M=6、EN=1、RESET=0；页面添加8事件、4检查点，POST 201保存草稿，version=1 |

| 学生旧版本 | 修改前打开的学生页面提交409，自动刷新并清空预测；本人记录仍只有原提交，没有错误新增尝试 |

## 发现与修正

1. 导航挂载测试原先把顶部空间文案当成只有“实验”，实际为“教师空间 / 实验”；修正断言为包含入口名，并保留精确导航高亮检查。
2. 并发走查发现同一会话的令牌轮换会先触发403。管理页现在保留编辑内容，提示再次保存并在下一次写入前获取新令牌；随后仍用原version进行乐观锁检查，不自动覆盖他处修改。真实多标签流程补验通过。

## 边界

本轮只验收教师实验管理，不把前端259项与相关后端33项称为全系统验收。未重跑全量后端、局域网、HTTPS、课堂负载或实际教师使用；页面内容较长，需要纵向滚动。四种模型继续依赖原仿真核心，零检查点序列允许保存与发布，但界面明确提示无法进行状态预测，没有擅自收紧接口规则。既有会话令牌策略未修改，本页处理其失败恢复。
