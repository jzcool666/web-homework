## 数据与交互

E050/E051 的 AttemptResult 仅新增只读 created_at，来自已存 UTC 创建时间，无迁移、请求字段、判分或权限变化。创建、幂等重试、列表与单条历史返回同一创建时间；客户端传入 created_at 被拒绝。实验图表按最近七个 UTC 自然日统计，排除无效、未来和窗外时间，按记录 ID 去重；活动次数统计尝试，完成比例仍按实验去重。

课程详情保留安全 Markdown、收藏与自报完成；切换知识点时旧操作响应不能覆盖新知识点。电路来自关联实验模型；输入采样不产生标准输出。实验切换保留当前页面会话内最近八个工作区的预测；刷新页面后未提交预测不持久化。作答继续使用原有防抖保存队列、版本锁、全部答案对象与提交前保存。

顶部搜索是实际入口：学生可搜索已发布知识点与实验，其他角色搜索本角色页面；没有使用假的通知按钮或统计数字填充界面。课程及分析标签支持方向键、Home/End；手机抽屉保留 Escape、焦点返回与路由切换关闭。
