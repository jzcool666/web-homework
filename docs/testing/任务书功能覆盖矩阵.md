# 任务书功能覆盖矩阵

版本：设计基线 1.0（范围校正），2026-09-28；2026-10-03 由 D7 更新验收状态列。状态：**原范围十六类功能已通过D7；实验辅助新增接线/文件测评已通过实验扩展验收并合入；最终收口结果见[最终验收与交付检查](最终验收与交付检查.md)**，逐类运行时证据见 [D7 集成验收报告](D7-集成验收报告.md) 第 10 节。本文把原始《Web高级编程》项目大作业任务书的每条功能、PRD 需求、Spec、GitHub Issue 与可测试验收逐项对齐，用于确认“十类基础功能 + 六类智能功能”不存在无归属条目。

课题限定为“数字逻辑课程学习系统（时序逻辑）”。任务书以通用平台描述同时提到“数字逻辑”与“计算机组成原理”，本项目只覆盖时序逻辑；触发器、计数器、寄存器与状态转换是全部课程内容、演示、实验、题库与智能数据的组织中心，不扩展到组成原理、运算器、存储器或指令执行。逐项结论见第 3 节。

Issue 号为本矩阵编写时的开发任务编号（开发仓库 [web-homework](https://github.com/jzcool666/web-homework)）；验收编号与[测试计划](需求追溯与测试计划.md)及对应 Spec 一致。SPEC-000 的执行结果另见[报告](SPEC-000-执行报告.md)，原18模块已有执行报告；新增SPEC-018/019已执行并合入。

## 5 依赖与开发顺序

公共工程/权限 → 知识与题库 → 仿真/随堂测/实验 → 备课串联 → 考勤与四类统计 → 智能功能 → 集成与提交。

- SPEC-000/001 为基础，其余模块依赖其一。
- SPEC-016 依赖 SPEC-005；SPEC-017 依赖 SPEC-012；二者属智能功能阶段，可与 SPEC-011/015 并行。
- 最终集成 #19 的前置必须包含 SPEC-016/017 对应的 #23/#24。

完整依赖见[Spec 索引](../specs/README.md)，阶段顺序见[实施计划](../design/实施计划.md)。
