## 1 改动与数据口径

保留 #48 的角色分发与分组导航；教师首页新增班级选择、当前课堂、快捷操作、最近测评与已有预警。学生首页突出课堂任务和继续学习，课程卡片、真实关联实验、题号作答导航与逐拍实验对照均已接入。学生个人学习分析路由 `/student/analytics` 与导航同步接通；教师实验管理仍待开放。

学习完成比例和实验通过比例只计当前可见已发布内容，列表分页读完再计算；实验至少通过一次且按实验去重。本次推荐知识点数不是全部待复习数；score=null 表示基础路径。教师班级切换清空旧数据并屏蔽迟到的旧响应，进入课堂/签到/测评/统计/预警时携带班级上下文，目标页只接受本人可选班级。

课程详情没有 simulator_type：概念框图从关联实验获得，无关联不猜测。实验标准输出只在提交后依据服务器 expected/actual 展示，逐拍 Q 对照不冒充完整半周期波形。作答 UI 仍使用原有答案对象、1 秒防抖保存队列、版本锁及提交前保存；题号切换不产生第二套答案状态。
