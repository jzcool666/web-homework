# 页面按钮布局检查记录

检查日期：2026-10-08。环境：Windows、本地同源构建页面、演示教师／学生／管理员账号及未登录状态。

## 检查目标

从测评页“创建草稿”按钮位置不合适的问题出发，检查所有现有页面的提交、筛选、编辑、分页和课堂操作按钮。要求按钮与所属内容关联清楚，不挤入输入栏，不相互重叠，窄屏下能换行，文字完整并可操作。

## 修改内容

- 测评创建：类型和标题独立排列，选题与分值编辑放在同一表单内，“创建草稿”移到选题之后的操作区。题库采用内部滚动，表头固定；已选题的分值与移除按钮在窄屏换行。
- 表单提交：考勤、备课、组卷、题库、课程内容、问答、个人资料、管理员维护及学生自练／签到／请假／电路上传的提交按钮放在所属表单末尾。
- 条件筛选：学情、出勤、实验统计、学习预警、题库、错题、识别、推荐、实验记录和知识图谱使用可换行的筛选栏，操作按钮与输入控件底部对齐。
- 窄屏：输入区改为单列；操作区可换行，长文案可折行；修正测评和组卷表单被表格最小宽度撑出页面的问题。备课条目与选题条目的操作不再挤压题干。

## 页面覆盖与结果

对照当前路由表检查全部 **47 个路由模式**。基础检查包含教师 25、学生 24、管理员 6、未登录 3 个角色页面场景，共 58 个场景；每个场景分别检查 **1366×768、1024×768、390×768**。

另检查选题后的测评表单、备课编辑、题目编辑、问答编辑、组卷知识点下限与生成结果、选中文件后的上传区、考勤名单展开、匿名统计投屏、实验箱只读投屏。合计 **68 个场景、204 组页面截图与布局数据**。每个场景均有三种宽度的记录。
