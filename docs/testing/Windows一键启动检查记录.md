## 使用边界

本轮验证为本机 Windows 和全新目录，不代替另一台电脑实测。Python3.12/3.13按依赖要求允许，完整启动实测版本仍为3.14；Node其他受支持版本亦需在目标电脑确认。缺少Java或官方下载失败时，会明确显示“电路文件测评未启用”，网站与接线模拟仍可启动；不把这种状态当完整测评就绪。

本次没有重新运行业务全量回归；既有业务验收按[最终验收记录](最终验收与交付检查.md)读取。本入口只监听127.0.0.1，正式课堂部署仍按[一键运行说明](../一键运行说明.md)中的手工部署入口配置。
