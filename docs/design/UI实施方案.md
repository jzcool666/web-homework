# UI 实施方案

版本：2.2，2026-10-03。适用于最终 UI 整理；业务契约仍以 PRD、APIC、DBD 与各 Spec 为准。以发起人提供的[六页视觉参考](六页视觉参考.png)作为桌面视觉验收基准，按真实内容适配布局。旧验收记录保留原代码范围，最新补验见[六页效果图实现检查记录](../testing/六页效果图实现检查记录.md)。

## 页面与顺序

1. 外壳：保留现有入口与权限，教师侧栏独立滚动，常用课堂入口置顶。学生学习分析随真实页面接通；教师实验管理作为独立增强已接通，真实输入序列编辑与版本校验见[检查记录](../testing/教师实验管理检查记录.md)。
2. 学生桌面首页：继续学习与四项实际记录指标、知识点卡片、复习建议与章节完成情况；右侧展示关联实验电路、输入采样与课堂任务。手机端课堂任务先于继续学习。教师首页：班级选择、蓝色课堂横幅、四项指标、当前课堂与快捷操作、最近测评与预警入口。管理员保持简洁。
3. 课程：章节知识点卡片、收藏与自报完成；详情按概念、电路结构、状态表、时序图、实验应用、相关习题六个标签组织，保留安全 Markdown 与真实资源。电路类型来自关联实验，没有关联实验就不展示猜测图。多个实验分别提供入口。
4. 练习：StudentPracticeView 负责选条件、生成与历史列表；StudentAssessmentView 负责题号导航、作答与保存。保持 1 秒防抖、保存队列、版本和提交顺序。
5. 实验：按模型筛选，左侧列表、右侧实验工作区；切换实验保留当前页面会话内的预测。预测页先展示输入与概念框图，提交后用服务端 expected/actual 做逐拍对照。不把检查点数组冒充完整半周期历史，不在前端重写仿真器。
6. 学生学习分析：当前已发布内容的学习与实验完成比例、章节完成情况、近七个 UTC 自然日实验提交/通过次数、本次推荐。时长与掌握度没有可靠口径，不伪造展示。E050/E051 的 AttemptResult 新增只读 created_at，沿用数据库已有 UTC 创建时间，无迁移或判分变更。
7. 收口：统一公共卡片、表格、按钮、边界状态，更新设计文档，在最终实现上完成前端测试、构建和真实浏览器验收。

2.2 细化：教师快捷操作改为2×2；课程概念页采用电路与原理同卡布局；学生实验增加逐拍输入查看与Q选择，沿用同一份预测，不生成标准答案；首页和实验用实际固定输入事件绘制完整CLK波形，学习分析增加真实习题记录标签。通用角色头像和课堂动态均接入已有数据，未改变业务规则。

## 统计口径

| 展示 | 来源与口径 |
| --- | --- |
| 已完成知识点 x/y | y 为当前学生可见已发布知识点；x 为其中 completed=true 的不同知识点。分页全部读取，y=0 比例为 null。完成是自报，不代表掌握。 |
| 已通过实验 x/y | y 为当前已发布实验；x 为其中至少有一次 passed=true 的不同实验。撤回实验与重复尝试不增加分子。 |
| 本次推荐知识点数 | /me/recommendations?limit=10 中 kind=knowledge 的去重个数，仅代表本次返回结果，不能称全部待复习数。score=null 标为基础路径。 |
| 继续学习 | 优先本次推荐中的知识点；无推荐则选章节顺序中未完成的点；全部完成则进入课程复习。不把 completed_at 读成阅读位置。 |
| 教师当前课堂 | 所选班级 active 演示与 effective_state=open 的班级测评；测评选择时排除自练。切班清空旧数据并防止旧请求覆盖新班。 |
| 最近测评 | 按 starts_at/id 倒序选择已发布或已结束班级测评；使用 assessment_id 单独请求统计，标明接口返回的 UTC 窗口。无测评/无提交展示空态，真实 0 与 null 区分。 |
| 预警 | 仅 GET 最近已有批次，不自动 POST 生成。无批次显示尚未生成。 |

分页读取失败时不展示部分列表计算的完整统计。首页各区独立处理失败，不能把接口失败显示为零；教师班级未选择时不请求班级接口。

## 视觉与验收

蓝白渐变背景、12px 卡片圆角与轻阴影；主标题 25px，正文 14px，卡片间距 14px。顶部提供真实搜索入口，学生可搜索已发布知识点与实验，教师按角色导航搜索页面。教师 Hero 仅作简短主题提示；1366×768 展示主要操作，390px 优先课堂任务与继续学习。桌面侧栏独立滚动，窄屏抽屉保留键盘、遮罩关闭与路由切换关闭。题号列表只导航，不创建第二套答案状态。

六页分别验收：学生首页的继续学习与右侧概览、教师首页的横幅与工作台、课程六标签与资源区、作答的题目列表与单题区、实验的列表与预测区、学习分析的指标与图表。内容数量、统计数值与参考图示例不要求一致；缺少真实数据时显示对应空态。

实拍至少覆盖教师首页、学生首页（桌面与手机）、课程列表与详情、作答、实验结果、学生分析、教师控制台与波形。运行证据包含保存失败/恢复、版本冲突、无班级、无内容、null/真实零和切班竞态的适当测试。

| 实验箱 上传 过程回放 记录详情 | 保留器件与线网视觉；强化接线、上电、操作、提交顺序和队列状态 |

公共页面标题和卡片先统一层次与间距，给适当页面提供简短操作步骤提示。提示以用户操作表述，不出现Spec编号、服务端文件名或算法实现字段；不为每页添加大型插画，不伪造未有的数据。表格可内部横向滚动，整页不横向溢出。已有六页、课堂和实验箱的专项视觉只做必要适配，不覆盖其交互。

知识图谱采用确定的位置装配，画布只显示API返回的实际节点和边，不推断新的先修关系。有环时仍按既有警告展示，不冒充拓扑结果。标题与提示用文本渲染，避免HTML格式器解释用户输入。

验收用完整模拟库，对所有路由配置实际可访问角色和对象ID，覆盖1366、1024、390尺寸。对截图逐页检查主要内容与操作；抽屉关闭、筛选、表单、保存/提交、发布、CSV、未公开反馈与版本冲突仍应可用。完整前端测试、构建和适当后端回归后记新报告，不把旧截图和模拟使用写成真实师生参与。
