# UI 设计基线

版本：2.0，2026-10-03。适用范围：学海通数字逻辑课程学习系统的前端页面。本文约束视觉与交互，不改变 PRD、APIC、DBD 或任何 Spec 的业务规则；页面与课堂流程以[已评审设计](页面与课堂流程.md)为准。

## 1. 设计目标

统一角色导航、首页与课程/作答/实验内容页；教师围绕班级与课堂，学生围绕课堂任务与继续学习。最终页面范围与数据口径见 [UI 实施方案](UI实施方案.md)。实施记录和新 UI 证据单独保存，不将旧 D7 截图当作本版本验收。

## 2. 设计原则

- 教师课堂优先：未来教师首页突出当前班级和“进入课堂”，学生首页突出本班当前活动；管理员首页保持简洁。
- 浅色教学界面，蓝色主操作，适量电路与波形线条提示课程主题。信息密度适中，主要内容用卡片分组。
- 能操作的内容必须对应已实现路由；计划入口显示“待开放”，不得伪装可用功能。
- 不使用假数据冒充真实用户统计。缺少数据使用 Empty State；演示种子数据须明确标注模拟数据。
- 用户看到的角色菜单只改善体验。后端是权限、班级归属、答案可见性和状态变更的最终来源。

## 3. 色彩

Token 在 `frontend/src/styles/tokens.css` 维护，页面不得散落大量私有颜色。主色 `--color-primary: #345ff1`，悬停 `--color-primary-hover: #244bd6`；页面背景 `#f4f7fc`，卡片 `#fff`；主文字 `#132044`，次文字 `#667493`，边框 `#e2e8f2`。成功、警告、错误分别使用 `--color-success`、`--color-warning`、`--color-danger`。色彩不能是唯一状态编码，必须同时有文字、数值或图形。

## 4. 字体

中文正文使用系统无衬线字体；标题层级为 1.75/1.25/1rem，正文 1rem，辅助文字 .875rem，标签 .75rem。二进制、状态表、CLK/Q(t)/Q(t+1) 建议使用 `--font-mono` 等宽字体。投屏页面由 SPEC-012 单独提高字号和对比度。

## 5. 间距

基于 4px：`--space-1/2/3/4/5/6/8` 分别为 4/8/12/16/20/24/32px。普通卡片内边距 24px，手机端 16px。页面与卡片之间按统一间距排列。

## 6. 圆角

小、中、大圆角为 `--radius-sm/md/lg`（8/14/20px）。输入、按钮用小圆角，卡片用中圆角，重点横幅用大圆角。

## 7. 阴影

卡片使用轻阴影 `--shadow-card`，抽屉和认证表单可用 `--shadow-popover`。阴影不代替边框或焦点标记。

## 8. 页面 Layout

`App.vue` 只选择认证布局或 App Shell；具体导航在 `frontend/src/navigation/index.js`。App Shell 包含固定 Topbar、桌面 Sidebar 和 Main Content，最大内容宽度由 `--content-max-width` 控制。登录与注册使用无侧栏的 Auth Layout。首页也可匿名浏览，但不展示用户数据。

## 9. Sidebar / Topbar

Sidebar 宽 `--sidebar-width: 15rem`，Topbar 高 `--topbar-height: 4.5rem`。当前路由高亮；班级名单子路由高亮“班级管理”。Topbar 提供品牌、当前空间、用户资料与退出。窄屏菜单按钮控制抽屉，遮罩可关闭，切换路由自动关闭。键盘焦点和“跳到主要内容”链接必须可用。

## 10. 学生导航

学习首页、课程学习与收藏、我的课堂、考勤与请假、习题训练、实验中心、状态表识别、复习推荐、学习分析、课程问答、知识图谱均有真实入口。学习分析读取本人现有接口，教师班级统计接口仍不向学生开放。

首页优先当前课堂任务与继续学习，推荐摘要只展示前三项；预习超过三项可展开。未入班与读取失败分别显示对应说明。

## 11. 教师导航

核心教学、内容与测评、数据分析、智能工具、课堂管理五组；侧栏独立滚动，不要求全部入口同屏。首页明确所选班级，当前课堂与快捷操作先于统计。

教师“实验”管理入口仍待开放，属于可选增强；实验统计、课堂演示与学生实验预测已可用。课程问答与知识图谱已有独立页面。

## 12. 管理员导航

管理首页、账号管理、班级管理和课程内容为已实现入口；班级名单从班级管理进入。管理员不设复杂仪表盘，也不默认获得教师的班级教学数据权限。

## 13. 基础组件规范

`PageHeader` 放标题、说明与操作；`SectionCard` 放一个主题内容；`StatePanel` 统一 Empty、Loading、Error、Forbidden；`StatusBadge` 用文字加颜色表达状态；`AppIcon` 使用轻量内联 SVG。表单、按钮、表格和消息样式由全局样式统一。仓库当前没有安装 Element Plus，因此只实现当前页面用到的轻量基础件；后续若引入 Element Plus，应按 Token 统一主题，不重复造轮子。

组件评估：复用 PageHeader、SectionCard、StatePanel、StatusBadge、AppIcon；新增 MetricCard、CircuitPreview、RecommendationList 与实验 AttemptComparison。完成比例使用原生 progress，null 显示暂无足够数据，真实 0 保留。推荐优先级不是掌握度；实验逐拍对照不是完整半周期历史。无需引入新的 UI 框架。

## 14. 页面状态规范

- Loading：说明正在读取什么，不用无文字的旋转图标。
- Empty / No class / No activity / No data：说明缺少的对象和下一步。业务统计缺失显示“暂无足够数据”，不能显示 0%。
- Error：展示可理解的原因并保留已输入表单；必要时提供重试。
- Forbidden：角色不允许的路由由现有守卫引导；API 仍负责独立鉴权。
- 数值 `null` 与真实 `0` 视觉上必须区分。0 可以是真实零分，null 表示不可计算或尚无数据。不得将 null 格式化为 0。
- 自练和课堂测评的答案时机按 PRD 与 SPEC-009/010，UI 不得提前暴露答案。课堂结束、草稿未保存、断线、版本冲突分别使用明确文字。

## 15. 响应式规则

1366×768：Sidebar 保持可用并独立滚动，主要操作能找到且不被遮挡，不要求所有导航项同时出现在首屏。宽度低于 850px：Sidebar 转抽屉，主内容占满宽度。390px：表单单列、Topbar 精简、表格容器可横向滚动，签到与作答等后续页面应保证基本操作。复杂电路与波形允许在局部横向滚动，不要求手机端复杂电路编辑。实际视口检查结果应随本 PR 记录。

## 16. 数字逻辑视觉元素规范

允许课程相关的电路框、网格、状态节点、时序线和二进制标记。首页 Hero 的装饰图形设置 aria-hidden，不承载实验数据；CircuitPreview 明确标为概念示意，不对应真实实验结果。实验提交后的逐拍 Q 对照使用服务器返回的 expected/actual，不冒充完整半周期波形。正式电路图、状态表与波形必须从统一状态模型生成，UI 不得另造一套业务状态定义；有效沿、复位与位序标注以 SPEC-012/013 为准。

## 17. 禁止事项

不大量使用纯表格组织学习主界面；不使用复杂动画、3D、拟真电子元件、炫技粒子或大量渐变；不引入无关装饰或重量级依赖；不制造假的 API、学习进度、正确率、成绩或班级活动；不把静态 UI 当作 Spec 完成；不通过隐藏菜单替代后端权限控制。
