# 实验箱接线与电路文件测评方案

版本：实验扩展设计 1.0，2026-10-03。状态：规划完成、待实现。来源为项目负责人转述的教师要求：必须模拟实验箱连线过程，并支持 Logisim 电路文件在线测评。原有 SPEC-012/013 的预置演示和预测判分继续保留；此前 D7 通过不代表本扩展已完成。

## 1 器材和软件选择

采用通用 74 系列数字逻辑教学实验箱：电源区、逻辑开关、手动时钟、DIP 芯片插座、逻辑指示灯和接线端子。参考高校数字逻辑实验器材，不绑定某一学校的商业箱型号。芯片用 74LS74、74LS161、74LS194，加 74LS00/04/08/32 门电路；引脚按 TI 原厂 DIP 顶视图绘制，显示缺口、1 脚、编号、信号名和低有效横线。资料依据见[调研](../research/实验箱与Logisim测评调研.md)。图形自行用 SVG 绘制，不复制教材整页或厂商照片。

文件测评统一为 **Logisim-evolution 5.0.0**，服务端 Java 21。选择依据是官方维护、当前稳定发行及可验证的时序测试能力，未取得版本使用率调查，不称为“使用人数最多”。提供官方安装下载链接及本项目模板；旧版原始 Logisim 或其他分支保存的文件提示在指定版本打开并另存，不承诺所有版本兼容。

## 2 四项必做实验

| 编码 | 芯片与目标 | 输入端口 | 输出和判定 |
| --- | --- | --- | --- |
| LAB-D | 74LS74 一路 D 触发器；接电源、D、时钟、异步清零与置位 | CLK、CLR_N、PRE_N、D，均 1 位 | Q，1 位；上升沿采样，下降沿保持，CLR_N/PRE_N 低时立即清零/置位 |
| LAB-C6 | 74LS161 配门电路实现同步置数的模 6 计数器 | CLK、CLR_N、EN，均 1 位 | Q，4 位，QD QC QB QA 从高到低；启用时 0→1→2→3→4→5→0，EN=0 保持，包括停在 5 时 |
| LAB-S4 | 74LS194 的并行装载、保持、左移和右移 | CLK、CLR_N、S1、S0、SR、SL 各 1 位，P 为 4 位 | Q，4 位，QA QB QC QD 从高到低；S1S0 为 00 保持、01 右移、10 左移、11 装载 P |
| LAB-FSM | 74LS74 两路及必要门电路实现两位 Gray 状态机 | CLK、CLR_N，均 1 位 | Q，2 位，Q1 Q0；清零到 00，逐拍 00→01→11→10→00 |

计数器参考接法：A/B/C/D 接 0，EN 同时接 ENP/ENT，`LOAD_N = NOT(EN AND (Q == 5))`，外部 CLR_N 接异步清零。完整译码 0101，不能把译码到 6 的异步回零混称为本实验的同步方案。状态机参考方程 `D1=Q0`、`D0=NOT Q1`；它只是参考接法，功能等价且符合器件范围的其他连线也能通过。

两种位序不同是芯片用途的明确选择：161 的 QA 是最低位；194 的 QA 位于寄存器显示最左边。每个界面同时显示芯片输出名与 Q 位号，避免把字母顺序当作统一权重。所有测试在初始未知状态后先执行有效清零；不默认实际芯片上电即为 0。

## 3 网页接线流程

学生进入“接线与电路测评”，选任务后看到空接线的实验箱和实验指导。任务固定芯片插座及可用器件，不做任意元件库或电路 CAD。学生按引脚连接电源、开关、时钟和 LED 端子，点击两个端子生成导线，选线可删除；支持撤销/重做、引脚提示、放大及横向滚动。线在画面上交叉不会自动连接，只有共享端子构成连接。LED 端子是实验箱已含限流和缓冲的逻辑探针，不要求学生另接电阻，也不计算电流。

接线必须在关电状态进行；改线、撤销、重做均留下事件。开电后服务器检查供电、活动功能单元所需输入和多驱动；错误显示对应芯片和引脚。学生改变开关、切换 CLK 0/1，观察 LED、引脚电平、状态表和逻辑波形；“打一拍”展开为 0→1→0 三个确定动作，不以浏览器定时器代替逻辑时钟。关电清除芯片状态，重新开电后需清零。

接线、开关、通断电、时钟及重置的事件由服务器按版本保存，可刷新恢复和逐步回放。页面区分本地尚未保存与服务器已保存；失败不显示保存成功。提交后服务器保存接线和过程快照，重新运行任务测试得到成绩。教师可选择本班学生记录查看连线、操作步骤、结果和回放；“过程记录”只表示系统收到的操作，不宣称证明操作者身份或学习时长。

## 4 接线仿真的实现

Vue 3 负责 SVG 端子、导线、交互及结果展示。Python 负责唯一一套芯片逻辑和连通图；前端不另写芯片计算或判分。新代码置于独立 `lab_*` 模块，保留既有 simulator.py 的同步高有效复位语义，不能直接套到真实芯片。

芯片目录描述固定器件型号、引脚方向、功能单元和电源脚。服务器把导线端点合并成电气节点，再传播门输出；逻辑值为 0/1/X/Z，X 为未知/冲突、Z 为未驱动。活动单元的未接输入不能按 TTL 的浮空偏高行为悄悄算 1。未使用单元可忽略，但使用一路输出即需连接该单元所需控制脚；整片电源脚必须正确。电源短路、两个主动输出相连和不收敛组合环路给结构错误，停止正式判分。

一次动作先让组合逻辑和异步控制稳定，再用同一动作之前的状态采样所有发生上升沿的时序单元，最后传播新输出。74LS74 的 PRE_N/CLR_N 同时低视为教学禁用状态，标 X 并提示，两者释放后必须明确清零或置位；不把不稳定释放过程当作确定输出。161 为异步清零优先，其次上升沿同步装载，再次 ENP 与 ENT 均高时计数；RCO=ENT 且当前 Q=15。194 按原厂模式表执行。

网页任务要求活动时序单元的CLK直接接箱CLK节点，不支持门控/派生时钟；接错给出明确诊断。这样同拍采样语义有确定边界，不以简化引擎假装支持任意时钟反馈。文件测评由真实Logisim传播，仅按任务输入输出行为验证。

每实验最多 8 片芯片、256 条导线、512 条过程事件；一次组合稳定传播最多 64 轮，操作重放默认限时 1 秒。上限为项目设计约束，性能仍需实测；超限提示创建新练习，不截断已保存过程。新的会话从空箱开始，服务器只接受受控动作，不接受客户端 q/score/passed 或整段伪造历史覆盖。

## 5 上传测评的实现

学生下载带 `main` 电路和指定输入/输出 Pin 的任务模板，在指定版本的桌面 Logisim 完成电路，上传单个 `.circ`。服务端解析 XML，核对版本、main、端口标签/方向/位宽、内置器件白名单和大小上限，通过后保存随机文件名及 SHA-256，返回排队记录。上传入口独立于课程资料上传，不向资料白名单直接加入可执行库。

独立 `flask lab-worker` 进程以数据库队列取任务，默认 1 个 worker，不在 Flask 请求或 import 时起线程，不新增 Redis/Celery。用固定 Java 可执行文件、固定 JAR 和参数数组调用 `--test-vector`，`shell=False`；英文输出固定解析 Passed/Failed 和各行结果。实际验证发现 5.0.0 的失败检查点也可能退出 0，因此**退出码只能表示运行情况，不是通过依据**。必须有完整的检查点计数，数量与私有向量一致；无汇总、解析失败、崩溃或超时为 error，成绩 null，不能当 0 分或通过。

时序向量每个独立场景有自己的 `<set>`，同场景 `<seq>` 从 1 连续递增，显式设置 CLK 低/高，并在开始时执行真实复位；不能每行重置状态。同一任务的两种测评使用同一版公开端口与行为要求、同一套私有输入/预期输出，分别由芯片引擎与 Logisim 运行。不比较电路文件文本或导线布局；有限测试的通过表示覆盖用例通过，不声称形式化证明。

共享测试集格式为`{suite_version,task_code,cases:[{set_id,steps:[{inputs,expected,scored:boolean}]}]}`；inputs/expected按公开端口表示固定位宽二进制位串，只允许0/1。每case从复位开始，适配器将顺序转成set/seq；非计分初始化expected省略并转don't-care，计分行所有输出必须有完整expected，每行算一个计分点。两个引擎都返回同一checkpoint编号；测试标准来自手册和人工推演，不能运行被测电路反生成期望。每任务至少覆盖两次完整循环/模式转换，以及保持、清零、下降沿；基础阶段冻结可运行参考和错误变体。

最多 2 MiB、16 个子电路、512 个器件、2048 条线、256 行向量；禁止递归子电路、DOCTYPE/实体扩展、外部 `.circ`/JAR/HDL、图像/文件引用、ROM/RAM、网络/终端和未知组件。允许受控 Pin/Constant/Splitter/Tunnel/Probe、基本门、D/JK 触发器、Register/Counter 和上述 TTL 芯片（具体内部名称在 LAB-0 以 5.0.0 源码及可运行样例冻结）。器件名称、库及属性都校验，不能只检查库标题。

每作业启动独立工作目录，JVM `-Xmx256m`、运行超时 15 秒、输出最多 256 KiB；超限终止本作业进程并记 error。worker 使用仅有作业目录写权限的运行账号部署；这不是一个可运行任意学生程序的通用沙箱。每学生最多 2 个未完成上传、间隔至少 10 秒；健康检查发现 Java/JAR/worker 不可用时返回可读服务错误。队列领取使用原子状态更新和租约，重启后的过期 running 记 error 可重试，不能写两次成绩。

worker启动时检查Java主版本、JAR哈希及自检样例；使用应用生成的本机heartbeat文件每5秒更新，上传入口只接受15秒内健康心跳，否则503、不保存queued。路径为服务端配置，不接受客户端路径；临时忙碌不等于失活，测评运行期间心跳仍更新。先支持同机单worker，服务账号的无登录运行条件须在实际部署验证，桌面探测不替代该验收。

首次部署以当前 Windows+Java 21 环境为准：普通 `--test-vector` 已验证无需打开主电路窗口可执行；设置 `java.awt.headless=true` 会触发 HeadlessException，故不能照抄“纯无图形 Linux 可直接跑”的部署描述。Linux 无显示环境若使用 Xvfb 须独立验证后再支持。测评 JAR 部署时从官方安装并核对哈希，课堂运行不临时联网下载，不将 JAR 和 JDK 放入 Git。

## 6 结果、历史与页面

两种提交共用 lab_attempts，区分 wiring/circ；保存任务版本、测试集版本、引擎版本、班级、连线/过程或文件哈希。队列状态为 queued/running/done/error；done 时 `score=round(100*passed_checkpoints/total_checkpoints,2)`，所有计分点通过才 passed=true。初始化动作的输出用 don't-care，不计分；不能把完整时钟的低/高两行重复当两个独立学习得分点。结构无效的网页连线返回 422，保留会话但不生成成绩；引擎故障为 error/null。

即时给出通过数、总分、分类原因和第一个失败输入/期望/实际；不返回完整私有测试文件、答案电路、服务器路径或原始命令输出。任务属练习、无发布截止和讲评开关，不复用测评系统的课堂保密模式。教师看本班学生姓名/学号和结果，可查看历史快照，学生只看本人。班级换教师后权限现算；退班不删除原记录，但不得以旧班级创建新提交。

新增页面：学生任务列表、接线工作台、上传/结果/本人历史；教师本班实验提交列表和过程/文件结果详情。教师投屏使用本人新建的演示会话，包含同一实验箱交互；正式学生列表不能作为匿名投屏页。共用现有 AppShell、导航和设计 Token，兼容当前 UI 精修工作，不另做视觉体系。复杂接线以桌面为主，390px 允许缩放/横滚并保证上传、读结果和关键按钮可用。

本扩展的统计先按任务/模式显示参与学生数、尝试数、通过人数和排队/错误数；done 才进入判分分母，无 done 时通过率 null。采用当前有效在册学生计算当前班级汇总，历史逐条记录仍按保存的 class_id 可查。不把新实验悄悄加到原 SPEC-014、预警或推荐的分母，后续接入另立明确变更。

## 7 开发顺序

LAB-0 冻结共享目录、四个行为规格和测试集，建立芯片引擎、三表迁移、会话/连线提交 API 及可运行参考电路。验收合入后 LAB-1 网页接线和教师查看、LAB-2 文件 worker 与上传界面可并行。LAB-1 独占 SVG 工作台和过程页面；LAB-2 独占文件校验、worker、上传页面；app 注册、路由/导航、APIC/DBD 和迁移变更由集成时串行处理。LAB-3 完成真实浏览器、真实 JAR、越权、队列恢复、备份和原课堂流程回归。
