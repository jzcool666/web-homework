# 数字逻辑课程学习系统用户手册

适用版本：2026-10-03，develop 5848440。系统用于时序逻辑课程，覆盖触发器、计数器、寄存器和状态转换。教师可以组织演示、签到和随堂测；学生可以学习、练习、预测状态、接线和上传电路。本手册按当前实际入口说明操作，不包含模拟电压或任意电路图片识别。

## 1 首次使用

用部署者提供的网址打开系统，在“登录”页输入账号与密码。教师与管理员账号由管理员建立；学生可从登录页进入“学生注册”，注册后由管理员加入班级。公开注册不能选择教师或管理员角色。

登录后点击右上角账号进入个人资料，可修改显示名；退出使用右上角“退出”。未分班时联系管理员，不通过修改页面或网址取得其他班权限。窄屏使用左上角按钮打开导航。

首次使用的顺序为：部署者安装并初始化管理员 → 管理员创建教师、学生及班级 → 教师准备课程和题库 → 学生加入班级 → 教师组织课堂。页面没有数据时先完成前面的步骤。

## 2 管理员

### 2.1 账号管理

1. 打开“账号管理”，填写登录名、显示名、角色和初始密码；学生账号还需填写学号。
2. 点击“创建”，检查账号列表中的角色和有效状态。
3. 不再使用的账号点击“停用”，恢复使用点击“启用”。账号停用后不能继续使用原会话。
4. 按页面提供的角色操作调整角色。最后一名有效管理员不能被停用或降级。

系统没有页面重置他人密码的入口；不要把修改显示名当成改密码。

### 2.2 班级和名单

1. 打开“班级管理”，填写班级名并选择任课教师，创建班级。
2. 从班级列表进入“名单”，选择学生并点击“加入班级”。
3. 使用名单里的移出或重新加入操作调整当前有效名单。学生只能有一个当前有效班级，退班不会删除历史记录。
4. 更换任课教师后，教学数据权限随班级当前任课教师变化；停用班级后不能发起新的教学活动。

管理员负责账号、班级和内容管理，不自动取得教师的本班教学数据权限。

### 2.3 课程内容

打开“课程内容”，创建章节和知识点，填写正文并按需发布。资源先建立基本信息，再追加文件或外链版本。支持PDF、PPTX、PNG、JPEG文件，单文件不超过20 MiB；外链使用http或https。版本只追加，不覆盖历史文件。学生看不到草稿；发布、撤回和追加版本只对本人内容提供操作。

## 3 教师

### 3.1 准备课程和题库

在“课程内容”准备章节、知识点和资源；在“题库”新增单选、多选或判断题，设置知识点、难度、答案和解析。多选按完整选项集合判分，少选或多选均不按部分正确给分。修改原题不会改写已经发布测评的题目快照。

### 3.2 备课和预习

1. 打开“备课”，点击“新建备课单”，填写标题、计划上课时间和备注。
2. 选择知识点、资源、题目或实验，点击“添加条目”，用上移下移调整顺序，保存备课单。
3. 选择班级与可选截止时间，点击“保存并发布”。发布时引用内容必须仍可见，成功后预习内容成为固定快照。
4. 学生在首页查看预习待办和条目摘要。题目预习摘要不含正确答案与解析，也不提供完整作答；随堂测应另行发布。
5. 用“复制”建立新的备课单，不把后来修改当成已经发布快照的更新。

### 3.3 管理预测实验

1. 打开“实验”，选择本人实验或点击“新建实验”。他人公开实验只读。
2. 填写标题、关联知识点、模型、初态和步骤；计数器额外填写模数2—16。D/JK初态为0或1，四位模型为0—15。
3. 用“设置输入”填写输入，用“一拍”或“半周期”安排时钟；可以调整顺序、移除事件或恢复初态。已有序列时先移除原序列，再更换模型。
4. “一拍”会在需要时先补下降沿，然后形成一个有效上升沿。检查点数量是学生需要预测的拍数；“恢复初态”清除之前累计的检查点。
5. 保存草稿仅本人可见；发布后学生可以练习；撤回为草稿后学生不再读取该实验。已有课堂演示和历史提交保留原快照。
6. 出现版本冲突时未保存内容保留，确认后点击“重新载入最新版本”会替换当前编辑内容。出现登录校验更新提示时可再次保存，不必先刷新丢弃草稿。

最多128个事件。零检查点序列虽然可以保存，但不能进行学生状态预测，发布前应添加有效沿。

### 3.4 课堂演示与投屏

1. 打开“课堂”，选择本班和一个实验主题，点击“开始演示”。每班同时只能有一个进行中的演示；已有演示可继续，也可先结束后换主题。
2. 在控制台拨动输入开关，点击“前进一步”观察一个有效沿后的状态；“切换时钟半周期”可单独讲解上升沿和下降沿。
3. 输入改变和下降沿通常保持Q；同步RESET只有上升沿生效。“复位到初态”是重新开始演示，与RESET输入不同。
4. 计数器观察状态图和输出灯；寄存器按SI→Q3→Q2→Q1→Q0观察移位。图中动画回放已经执行的动作，不表示真实传播延迟。
5. 先隐藏下一状态，请学生预测，再揭示或推进验证。隐藏时学生端也没有下一状态数值。
6. 点击“投屏”，打开独立演示页并使用“全屏展示”。控制在原窗口完成；投屏页只读，不显示账号侧栏和学生成绩。波形与状态表可展开。
7. 演示结束点击“结束演示”。网络中断或版本冲突时先看提示与服务器最新状态，不连续重复点击动作。

学生从“我的课堂”进入本班演示，同步读取教师操作结果；隐藏浏览器页签时停止轮询，重新显示后恢复。

### 3.5 随堂测和讲评

1. 打开“测评与讲评”，选择班级，填写类型和标题，创建草稿。
2. 进入详情，用题目选择器组卷并保存草稿；设置开始、结束时间，点击“发布并冻结”。发布后名单和题目快照固定。
3. 学生从首页课堂任务或“习题训练”的测评列表进入。教师进度显示名单、已提交、白卷、提交率与平均分等聚合信息，目前没有逐人“谁还没交”列表。
4. 必要时“提前结束”；结束不等于公开，学生仍等待讲评。
5. 点击“公开反馈”后，学生才能看到分数、正确答案和解析。教师可查看逐题选项分布和漏答情况。
6. “投屏统计”只展示匿名聚合，不展示学生身份和逐题答案。

截止以服务器时间为准。自动结束会最终化已经开始的作答；未开始者不产生提交记录。提交率以发布名单为分母，平均分只含已提交者，白卷按0分计。

### 3.6 签到和请假

1. 打开“签到与请假”，选择班级，填写标题、开始、迟到与结束时间，点击“发布签到”。
2. 把一次性显示的六位签到码当堂公布。关闭显示后不能查询明文；需要更换时点击“重置签到码”，旧码立即失效。
3. 查看签到名单。迟到、截止和缺勤由服务器时间判断；点击“结算”确认结束状态，读取时也会结算到期任务。
4. 在请假申请区点击“批准”或“驳回”。批准待签到学生的请假会改为请假，已签到记录不会被改成请假。

同一学生同一任务重复签到不会新增记录。短时间多次输入错误码会暂时限流。

### 3.7 查看统计和预警

- “学情分析”：查看当前在册学生的知识点完成快照和资源访问统计，可筛选章节及日期并导出CSV。完成是学生自报，不表示精确历史掌握率或学习时长。
- “实验统计”：查看已发布预测实验的参与、通过、尝试数与通过率。同人多次尝试只算一个参与者，任一次通过算通过者；无参与的通过率显示“—”。
- “出勤统计”：查看本班出勤及关联因素，按页面口径筛选和导出；缺失样本不能当成0。
- “学习预警”：选择窗口并生成快照，再查看预警等级、因素与相似表现分组。预警是教学参考，样本不足可能没有分组；不能把规则分数当成精确掌握度或个人评价。

统计日期按UTC自然日，边界相当于北京时间08:00；测评和签到表单输入本地时间，保存后统一由服务器处理。导出只包含当前账号有权限的本班数据。

### 3.8 智能组卷

打开“智能组卷”，选择班级、类型、标题、题量、难度配额及知识点最低题数。难度配额之和必须等于题量。生成成功得到测评草稿，核对题目后按3.5发布。无解时减少冲突条件或补题；超时与无解分别提示，不把超时当成题库不足。

### 3.9 问答和知识图谱

教师“课程问答”用于准备、编辑和发布可检索的问答条目。学生提问只匹配已审核发布的语料，返回来源和知识点；低匹配时不给出编造答案。

“知识图谱”显示知识点先修关系，可按章节、根节点和深度查看子图，选择起点、终点查询先修路径。没有路径或数据时显示对应空态；文字节点与边清单可供核对。图谱不开放任意关系编辑。

### 3.10 实验箱和电路测评

在“实验箱与电路测评”选择任务与本班，可新建接线演示及投屏；从“实验记录与统计”查看本班学生的接线回放、文件测评和统计。教师对学生过程只读。接线箱的低有效异步清零规则与3.4的预置同步模型不同，应按各任务说明讲解。详细操作见[实验箱与电路测评使用说明](实验箱与电路测评使用说明.md)。

## 4 学生

### 4.1 学习课程

打开“课程学习与收藏”，搜索或按章节选择知识点。详情中阅读概念、结构、状态表、时序图及关联内容，查看资料版本，收藏需复习的知识点，按自己的实际学习情况标记完成。未发布内容不可见；完成记录可取消，不能把它当成考试成绩。

首页“继续学习”、课堂任务和复习建议来自本人真实记录。预习待办展示固定摘要；完整知识点和资源从相应学习入口阅读。

### 4.2 自练和错题

在“习题训练”选择知识点、难度和题量，点击“生成自练”。题库不足时按实际可用数调整条件。单选、判断选一个答案，多选选择完整集合。提交后读取服务器结果，查看答案和解析；到“错题本”筛选未纠正题并重练。重练答对会更新纠正状态，不删除历史错误，也不改首答记录。

### 4.3 参加课堂测评

从首页课堂任务或“习题训练”的测评列表进入已发布活动。选择答案后留意“已保存”时间；页面有短延迟自动保存，关闭前应确认保存成功。网络断开或保存失败时保留当前页面，恢复后再保存；提交前会等待保存确认。

刷新可恢复服务器已保存的答案；未保存内容无法由服务器恢复。截止由服务器判断，已提交作答不可改写。反馈未公开时只显示本人的作答，分数和答案待教师公开后再查看。

### 4.4 观看课堂和签到

“我的课堂”用于观看本班教师演示，只读输入、时钟和当前状态；下一状态跟随教师的隐藏或揭示设置。

“考勤与请假”中选中签到任务，输入教师公布的六位码签到；批准请假后不必签到。需要请假时在任务结束前填写理由提交，教师可在结束后审批。重复签到不会改变已有记录；使用旧码或错误码会收到提示。

### 4.5 预测实验

1. 打开“实验中心”，按模型选择已发布实验，阅读初态、输入流程和步骤。
2. 每个检查点填写有效上升沿后的Q。D/JK填0或1；四位模型填0—15的十进制数，界面同时显示位序。
3. 点击“提交预测”，服务器计算标准状态，返回通过情况、首个错误与逐拍说明。
4. 修改练习内容可“重新作答”；从记录入口查看本人历史。教师修改版本后，旧页面提交会提示刷新并清空旧预测，需要按新版本重填。

### 4.6 实验箱接线和文件测评

从“实验箱与电路测评”选择D触发器、模6计数器、寄存器或Gray状态机。先关电接VCC/GND及信号，再按任务说明清零、上电和推进时钟。连线交叉不表示相连，可追踪导线并查看端点列表；上电X是未知，关电或悬空Z不是0。提交接线测评后读取服务器测试结果，历史快照保留。

上传电路时先下载端口模板，在Logisim-evolution 5.0.0完成并保存`.circ`。入口main和Pin名称、方向、位宽须与任务一致，文件不超过2 MiB；外部库、HDL和存储器等不支持。上传后等待worker测评，结果有分数、首错和原文件下载。测评故障的成绩为空，可以重新上传，不把故障当成0分。完整步骤与支持范围见[实验箱使用说明](实验箱与电路测评使用说明.md)。

### 4.7 状态表识别

打开“状态表识别”，选择班级和PNG/JPEG图片，单文件不超过20 MiB。图片必须是白底黑线规则网格，恰好4列、2—17行，每格一个印刷体0或1，无表头、合并格或手写内容；从左到右Q3、Q2、Q1、Q0，从上到下为连续时钟拍。

查看识别出的状态与次态转换，并人工核对。该功能不识别任意电路图或手绘图，不参与实验判分。网格不清、字符不确定或处理超时分别提示，按提示重新准备图片。

### 4.8 复习推荐和学习分析

“复习推荐”结合本人公开反馈的错题、学习进度和实验记录给出知识点或练习建议，查看理由后进入关联内容。缺少记录时给出基础路径，分数为“—”，不是0分。

“学习分析”查看本人当前内容完成比例、章节完成情况、近七个UTC自然日活动和实际习题记录。自报完成、推荐优先级和通过次数各自表达不同含义，不能解释为精确掌握度或学习时长。

### 4.9 问答和图谱

在“课程问答”输入具体问题并检索，查看匹配语料、来源与知识点；没有可靠匹配时改用课程检索或联系教师。在“知识图谱”查看先修关系和路径，按3.9的方法查询，不会获得其他学生记录。

## 5 部署者首次初始化

安装与启动以[README运行步骤](../README.md#运行步骤)为准，Java测评另按[实验箱部署说明](实验箱与电路测评使用说明.md#管理员部署)。下面为已实现命令的顺序，工作目录为backend，参数按实际账号填写：

```powershell
python -m flask --app app:create_app db upgrade
python -m flask --app app:create_app init-admin --login-name <管理员登录名> --password <初始口令>
# 管理员在页面创建教师后，使用该教师登录名
python -m flask --app app:create_app seed-content --owner-login <教师登录名>
python -m flask --app app:create_app seed-experiments --owner-login <教师登录名>
python -m flask --app app:create_app seed-qa --owner-login <教师登录名>
python -m flask --app app:create_app seed-labs
```

前端目录执行`npm ci`和`npm run build`，然后在backend用`waitress-serve --listen=127.0.0.1:5000 wsgi:app`启动同源服务；局域网访问再按部署环境设置监听地址。生产环境提供数据库地址与随机密钥，并配置HTTPS以使用默认Secure会话Cookie。`.env.example`是模板，不包含真实密码。首次种子只提供课程、实验与问答，不自动建立完整课堂和学生成绩。

文件上传测评还需配置Java21、官方5.0.0 JAR路径，并单独运行`python -m flask --app app:create_app lab-worker`；Web与worker共用数据库和上传目录。worker就绪后再上传电路。

备份和恢复按README及`scripts/backup.py`、`scripts/restore.py`操作。恢复前停止Web和worker，确认目标为空且保留原备份；不得在有学生新提交的库上直接回退迁移。

## 6 常见提示

| 提示或现象 | 处理 |
| --- | --- |
| 没有班级 | 管理员确认学生有效入班关系或教师任课关系 |
| 没有课程、题目或实验 | 教师先创建并发布内容，或部署者按顺序运行相应种子 |
| 内容不存在 | 内容可能撤回、版本改变或账号无权限，不尝试猜测他人编号 |
| 版本冲突 | 先保留需要的编辑文字，按提示明确载入最新版本，再决定是否重新操作 |
| 尚未保存或连接中断 | 保留当前页，恢复网络后确认保存回执，避免把本地选择误认为已上交 |
| 反馈未公开 | 等待教师公开；结束活动不自动公开答案 |
| 无解与超时 | 无解调整组卷条件或补题；超时稍后重试，不能合并成一个原因 |
| 电路测评服务不可用 | 部署者核对worker状态、Java/JAR、数据库与上传目录；其他学习流程仍可使用 |
| 统计为“—” | 数据缺失或分母为0，不能当成0%或0分 |

## 7 入口核对
