# Windows 一键运行

适用于 Windows 10/11 的本机查看和演示。先解压完整项目，再双击根目录的 **一键启动.cmd**。不要在压缩包内直接运行。

## 首次准备

**GitHub Release 的 Windows64位离线包**已经包含 Python、Java、Logisim、依赖和构建页面，直接按使用步骤启动，无需下述开发工具安装或首次下载。包内 `portable.json` 用于识别离线版；不要删除。运行数据仍只保存在 `.local-run/`。发布文件、校验及交付后事项见[发布与交付说明](发布与交付说明.md)。

以下安装步骤适用于源码包。

电脑需安装 64 位 [Python 3.14](https://www.python.org/downloads/windows/)（支持 3.12—3.14，安装时勾选 Add python.exe to PATH）和 [Node.js 24 LTS](https://nodejs.org/en/download)（含 npm）。目前完整实测环境为 Python 3.14.7、Node 24.18.0；其他受支持版本仍需在目标电脑确认。电路文件测评另需 [Java 21](https://adoptium.net/temurin/releases/?version=21&os=windows&arch=x64)。装完后重新打开启动器。

首次运行需要网络下载项目依赖与官方 Logisim-evolution 5.0.0；已准备好且源码未变更时，后续启动不重复安装或构建。下载只使用官方 Logisim [发布资产](https://github.com/logisim-evolution/logisim-evolution/releases/tag/v5.0.0)，SHA-256 必须为 `6b368e894742c04cc83aa9830f869bcab0190ede4df43ad6fecdb89b3a23a41c`。

## 使用步骤

1. 双击 **一键启动.cmd**。窗口依次检查环境、安装依赖、构建前端、升级专用库并准备完整模拟示例。
2. 启动完成后自动打开 `http://127.0.0.1:5336`。窗口显示教师 `demo_teacher_a`、学生 `demo_student_01`、管理员 `demo_admin` 及本机随机生成的演示口令。三类账号使用同一初始演示口令；初始化后更改的账号口令仍以实际为准。
3. 保留启动窗口。结束时双击 **停止运行.cmd**，或在启动窗口按 Ctrl+C。已有内容、提交记录和附件会保留。

没有合适的 Java 或 Logisim 下载失败时，网站和接线模拟仍会启动，窗口明确显示“电路文件测评：未启用”。安装 Java/准备 JAR 后重新启动即可。完整启动以窗口显示“电路文件测评：已就绪”为准，它表示独立 worker 已完成真实 Logisim 自检。

重复点击启动不会创建第二套服务；首次安装期间重复点击会提示“正在准备”。停止入口仅请求本项目启动器停止，不会根据过期 PID 文件关闭其他程序。直接关闭启动窗口时，Web 与 worker 通过父进程句柄检测退出；按上述正常停止方式更便于确认结果。

## 数据、配置和故障定位

所有一键运行数据放在项目的 `.local-run/`，该目录不进入 Git 和源码包：

| 文件/目录 | 用途 |
| --- | --- |
| settings.json | 自动生成的会话密钥、初始演示口令、端口及可选 Java/JAR 路径 |
| demo.sqlite、uploads/ | 独立演示库和上传附件 |
| venv/ | 本项目 Python 环境 |
| tools/ | 官方 Logisim JAR |
| logs/setup.log | 安装、构建、迁移及种子初始化结果 |
| logs/web.log、logs/worker.log | 本次网站和测评进程输出 |

启动器不读取 `backend/.env` 的数据库配置，也不连接原先的验收库或正式账号库。重复启动仅升级该专用演示库并幂等检查模拟示例，不会重置口令、成绩、截止时间或历史。初始进行中随堂测过期后，教师正常创建新任务。

端口占用时启动器会停止并给出提示，不关闭占用程序。可在停止状态下修改 `.local-run/settings.json` 的 `port`，例如 `5337`。不要删除其中的 `secret_key` 和 `demo_password`；它们为本机生成的配置。修改 `demo_password` 不会重置已有账号口令。

Java 可自动从 JAVA_HOME、PATH、用户 `.jdks` 及常见安装目录查找。也可在 settings.json 的 `java_path` 填写 java.exe 完整路径，在 `jar_path` 填写官方 5.0.0 JAR 完整路径；JSON 中的 Windows 反斜杠需写成 `\\`，或使用 `/`。显式路径无效时不会悄悄改用别的文件。也支持环境变量 LAB_JAVA/LAB_JAR，settings.json 非空路径优先。

下载失败可手动把官方 JAR 放到 `.local-run/tools/logisim-evolution-5.0.0-all.jar` 后重启；启动时仍校验哈希。依赖安装失败先检查网络和 logs/setup.log，修复后再次双击即可继续。

启动器只监听本机回环地址，适合演示。正式课堂的局域网、HTTPS、账号与备份配置按 [README](../README.md#运行步骤) 和 [用户手册](用户手册.md) 执行。

本机首次准备、真实文件判分、数据保留和停止验证见[Windows一键启动检查记录](testing/Windows一键启动检查记录.md)。

命令行也可调用 `python scripts/start_local.py start --no-browser`、`python scripts/start_local.py start --without-grader` 或 `python scripts/start_local.py stop`。批处理自动化执行可先设置 `LOCAL_RUN_NO_PAUSE=1`，避免退出时等待按键。
